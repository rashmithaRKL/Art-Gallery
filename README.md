## 🎨 Art Gallery Website

A clean and visually engaging Art Gallery website created using HTML and CSS.
Designed to showcase beautiful art collections, promote online exploration, and offer a seamless browsing experience for art lovers.

## 🚀 Features

🖼️ Elegant, modern homepage design

🛒 "Shop Now" and "Explore" interactive buttons

🎨 Beautiful art slider showcasing featured artworks

📝 "Why Choose Us" section to highlight gallery values

📱 Fully responsive layout (mobile, tablet, desktop)

🌟 Simple and clean HTML5 & CSS3 structure

⚡ Fast-loading and lightweight



## 🛠️ Built With

HTML5

CSS3


    
## 📢 How To Use

Clone or download the repository.

Open the index.html file in any web browser.

Customize the images, text, or colors to fit your gallery's brand.


## ✨ Customization Tips

Replace artwork images in the images/ folder.

Update titles, subtitles, and button texts directly inside the index.html.

Modify styles like colors, fonts, and layout inside the style.css.
